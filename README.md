# 상권 Atlas — 한국·일본 출점 검토 MVP

음식점을 열기 전 **내 예산과 운영 조건으로 업종을 좁히고, 동네·경쟁점·매물 비용을 확인하는 모바일 중심 정적 웹 앱**입니다. PC에서는 같은 기능을 넓은 화면으로 사용할 수 있습니다. 자료 확인일은 **2026년 10월 24일**이며, 전국 서비스나 실시간 데이터 공급이 완성된 제품은 아닙니다.

## 사용 흐름과 현재 기능

1. **업종 찾기:** 국가·동네, 총 창업 예산, 영업시간, 경험, 선호 운영 형태를 입력합니다. 한식 정식·도시락 포장·면 덮밥·카페 디저트·주점·구이의 6개 기본 운영안 중 최대 3개 검토 우선순위를 보여줍니다. 조건을 통과한 후보가 없으면 추천을 채우지 않습니다.
2. **동네 분석:** 거주·상주인구, 생활인구 연령 구성, 직장·사업장 종사자, 한국의 시간대 구간 구성과 후보 지역 위치를 확인합니다.
3. **매물 & 손익:** 공개 매물을 참조하거나 추천 운영안의 가정을 적용해 손익분기 판매량, 목표 이익을 남길 월세 상한, 초기 필요 현금과 예산 부족액을 계산합니다. 비공개 비용은 공란으로 적용하며 확인 또는 명시적인 가정 입력 전에는 계산·저장을 막습니다.
4. **경쟁점 조사:** 한국의 공식 업종별 점포 집계와 출처를 확인한 주변 조사 후보를 보고, 직접 점포·가격·현장 메모를 추가합니다. 현장 점검 목록도 지역별로 저장합니다.
5. **내 출점 검토:** 추천 카드 또는 손익 운영안을 저장하고, 같은 통화의 초기 현금·손익분기·월 이익 가정을 비교합니다. 불러와 수정하거나 저장한 운영안·직접 추가한 점포 기록을 JSON 파일로 내보낼 수 있습니다. 파일 다시 가져오기와 계정 동기화는 아직 없습니다.

휴대폰 브라우저에서 홈 화면 추가를 지원하면 바로가기로 사용할 수 있습니다. 완전한 오프라인 동작이나 네이티브 앱 설치를 보장하지 않습니다.

한국은 **공식 상권 영역**, 일본은 **町丁目 전체**를 비교합니다. 지도 핀은 지역의 대략적인 대표 위치이며 매물 건물이나 통계 경계를 나타내지 않습니다. 지역별 면적이 다르므로 절대 인구를 인구밀도로 읽지 않아야 합니다.

## 데이터 해석과 현재 한계

- **실시간·자동 갱신은 미연결입니다.** 갱신 가능 공급원은 출처 화면에 안내하며, 현재 값은 수록된 스냅샷입니다. 원자료 관측기간과 앱 조회일은 다릅니다.
- **한국 길단위인구는 추정·배분 자료입니다.** 원자료 총계의 정확한 일 단위 집계와 중복 제거 정의가 확정되지 않아 일평균·고유 방문자·점포 앞 실제 보행자 수로 환산하지 않습니다. 원자료의 `연령구간10` 범위도 확인 전이므로 0–19세 등으로 임의 변경하지 않습니다.
- 한국의 `2026년 2분기 수록`은 모든 지표가 그때 측정됐다는 뜻이 아닙니다. 상주·직장·생활인구의 원천 기준일과 작성 방식이 다릅니다. 해당 행의 원천일이 확인되지 않은 항목은 미확인 상태로 둡니다.
- 일본 주민 자료는 2026년, 종사자 자료는 **2021년 6월 1일** 기준입니다. 종사자 수는 현재 오피스 출근자나 낮 체류인구가 아닙니다. 두 자료로 동시점의 주야간 인구비를 만들지 않습니다.
- **경쟁점의 실제 구매 고객 연령은 미확인입니다.** 주변 주민 연령이나 리뷰 작성자의 외모로 추정하지 않습니다. 공개 주소를 대조한 점포 12곳은 주변 조사 후보이며, 현재 영업 여부·공식 상권 경계 내부·가격대를 검증한 전수 목록이 아닙니다. 점포 카드의 시간대는 현장 조사 계획이며 실제 혼잡 시간의 관측·예측이 아닙니다.
- 한국의 공식 점포 수는 해당 분기 운영 및 폐업 점포를 포함합니다. 현재 영업점 수로 표시하지 않으며 가맹점 수를 전체에 다시 더하지 않습니다. 6상권 × 10업종 가운데 성수 치킨전문점의 미공개 행은 0으로 만들지 않았습니다. 면적당 점포 수도 수요·매출·점포 규모를 보정한 경쟁 강도가 아닙니다.
- 업종 카드는 수요 검증을 위한 조사 가설입니다. 매출·성공 확률을 예측하거나 추천 순위를 보증하지 않습니다. 서울 업종별 추정매출은 공급 후보로 안내하며 개별 점포 실제 매출로 표시하지 않습니다.
- 매물은 공개 원문의 참조 사례입니다. 현재 공실, 계약 가능 여부, 인허가, 음식점 허용, 부가세, 관리비·보증금·양도금 등은 원문과 중개사에게 확인해야 합니다. 미확인 비용은 임의로 0으로 확정하지 않습니다.

## 업종 검토 규칙과 손익 계산

`dist/recommend.js`는 브라우저와 Node에서 공용으로 쓰는 순수 규칙 모듈입니다. 예산에 못 미치는 운영안과 시간·공간·경험 조건에 맞지 않는 운영안을 보류하고, 나머지를 예산 여유·경험·선호 형태·시간 구성으로 비교합니다. 결과의 **내조건맞춤 비교점수는 성공확률이 아닙니다.** 업종별 금액·객단가·인력·면적·판매량은 수정 가능한 계획 가정이며, 시장 평균이나 실측 최소 창업비가 아닙니다. 기본 계획의 권리금·양도금 0도 실제 매물에서 다시 확인해야 합니다.

시간대 점수는 사용자의 운영 가능 시간과 후보가 살펴보는 시간 구간의 교집합을 사용하고, 3–6시간으로 다른 구간 폭을 보정합니다. `lunch`는 점심·낮(06–17시), `evening`은 저녁(17–24시), `allday`는 종일 가능 조건입니다. 상대 구성 참고치를 시간당 방문객이나 실제 구매 고객으로 해석하지 않습니다. 연령 구성·직장인구·경쟁점 총수에는 수요 점수를 주지 않으며, 일본의 시간대 자료가 없으면 지역 수요 적합성은 미확인으로 남깁니다.

`dist/domain.js`는 입력 가정만 계산합니다. 좌석 또는 포장 처리량으로 만든 매출 시나리오는 입지의 실제 수요 예측이 아닙니다.

- 손익분기 월매출 = 월 고정비 ÷ (1 − 변동비율)
- 필요 영업일당 판매량 = 손익분기 월매출 ÷ 객단가 ÷ 월 영업일
- 좌석형 월매출 = 좌석 × 하루 최대 회전 수 × 가동률 × 객단가 × 월 영업일입니다. 포장형은 하루 주문 처리 상한 × 가동률 × 건당 금액 × 월 영업일이며, 판매량 단위는 고객 수가 아닌 주문 건수입니다. 화면에서는 좌석·회전 수 대신 주문 처리 상한을 입력합니다.
- 고정비에는 감가상각을 포함합니다. 원금 상환 후 현금은 영업이익에 감가상각을 더하고 대출 원금을 차감한 세전 단순 계산입니다.
- 초기 현금 필요액은 **보증금 + 권리금·설비양도금 + 공사·설비비 + 개점 부대비 + 예비 운영자금**의 5항목 합계입니다. 조달 대출액 차감 전이며, 환급성 보증금도 초기에는 현금이 필요합니다. 중개료·보증료·허가비 등은 개점 부대비에 반영합니다. 예산을 넘는 계산안에는 부족액과 초과 알림을 표시합니다.
- 매출·비용의 세금 포함 기준을 맞춰 입력해야 합니다. 부가세·소비세·소득세·법인세를 자동 계산하지 않습니다.
- 한국은 KRW, 일본은 JPY를 사용하며 입력과 저장 기록을 국가별로 분리합니다. 국가 전환은 환율 변환이 아닙니다.

## 지도·외부 링크·저장

지도 배경은 외부 MapLibre GL 및 OpenFreeMap 리소스를 사용합니다. WebGL2 등 지도 실행 환경이 지원되지 않으면 **좌표 기반 위치 비교도**와 비교표를 사용합니다. 위치 비교도는 길찾기용 지도나 도로·보행 동선 정보가 아닙니다. 외부 지도로 이동할 수 있는 링크도 제공합니다.

공식 자료·매물·지도 링크는 해당 제공자의 외부 사이트를 엽니다. 로그인, 가용성, 표시 내용은 제공자에 따라 달라집니다. 원본 출처와 지도 저작자 표시는 유지해야 합니다.

국가 선택, 국가별 예산·재무 가정, 저장한 운영안, 지역별 점검 항목, 직접 추가한 경쟁점 기록은 **현재 브라우저의 localStorage**에 저장합니다. 서버 계정 동기화나 자동 백업은 없으며, 브라우저 데이터 삭제·다른 기기·다른 사이트 주소에서는 기록이 유지되지 않을 수 있습니다. 내보내기 파일은 저장한 운영안, 직접 추가한 점포 기록, 지역별 현장 체크 상태를 담습니다. 아직 저장하지 않은 현재 재무 입력은 포함하지 않으며 파일 가져오기는 지원하지 않습니다. 직접 추가한 점포 기록은 수정·삭제할 수 있고 삭제 직후 되돌릴 수 있습니다.

## 실행과 검증

별도 빌드나 패키지 설치 없이 `dist/`를 정적 서버로 제공하면 됩니다. 파일을 직접 여는 `file://` 방식은 JSON 불러오기가 제한될 수 있습니다.

```bash
cd /path/to/tokyo-food-atlas
python3 -m http.server 8080 --directory dist
```

브라우저에서 `http://localhost:8080`을 엽니다. 지도 배경에는 인터넷 연결이 필요합니다. 통계와 계산기는 저장소에 포함된 파일을 사용합니다.

Node.js가 있는 환경에서 재무·추천 규칙 검증을 실행합니다.

```bash
node tests/finance.cjs
node tests/recommend.cjs
```

검증 범위는 알려진 손익분기 사례, 목표이익 항등식, 음수 임대료 상한, 회계이익과 현금의 차이, 잘못된 비율·입력·범위 초과, 착석률 0%, 예산 부족 시 후보 제외, 경험·선호 조건의 순위 변화, 실제 영업시간 교집합, 지역·경쟁 자료 누락, 연령 추정 및 점포 총수 단순 감점 방지, 입력 불변성과 브라우저/Node 내보내기입니다.

## 파일과 자료 재현

| 파일 | 용도 |
|---|---|
| `dist/index.html`, `dist/styles.css`, `dist/app.js` | 화면과 브라우저 동작 |
| `dist/domain.js` | 통화 중립 재무 계산 모듈 |
| `dist/recommend.js` | 6개 계획 운영안의 설명 가능한 비교 규칙 |
| `dist/data.json` | 앱이 실제 표시하는 확인 시점 스냅샷 |
| `dist/competition.json` | 서울 6상권의 공식 음식업종 집계와 자료 정의·출처 |
| `dist/rivals.json` | 공식 주소를 대조한 주변 점포 조사 후보 12곳과 출처 |
| `dist/provenance-korea.json` | 한국 공식 자료의 추출값·출처·집계 근거 |
| `dist/provenance-japan.json` | 일본 공식 자료의 추출값·출처·집계 근거 |
| `dist/provenance-korea-listings.json` | 한국 공개 매물의 확인 내역 |
| `dist/manifest.webmanifest`, `dist/icon.svg` | 홈 화면 바로가기 메타데이터와 아이콘 |
| `inputs/*.json` | 인구·매물·경쟁점 자료의 검증된 중간 입력과 추출 근거 |
| `prepare-data.py` | 포함된 인구·매물 입력을 기본 앱 스냅샷으로 변환하는 준비 스크립트 |
| `tests/finance.cjs` | 독립 재무 검증 |
| `tests/recommend.cjs` | 예산·시간·경험·자료 해석·추천 재무 가정 검증 |

**현재 화면 재현에는 포함된 `dist/`만 필요합니다.** 기본 인구·매물 스냅샷과 출처 파일은 프로젝트 안에서 `python3 prepare-data.py`를 실행해 포함된 `inputs/population-verified.json`, `inputs/korea-verified.json`, `inputs/korea-listings.json`으로 재생성할 수 있습니다. 경로는 스크립트의 위치를 기준으로 합니다. 별도로 포함된 `competition.json`과 `rivals.json`은 이 스크립트가 갱신하지 않으며, 원본 중간 자료는 각각 `inputs/competition-verified.json`, `inputs/rivals-verified.json`에 있습니다.

이 준비 스크립트는 실시간 수집기가 아니며 원천 문서 취득·추출 검증을 대체하지 않습니다. 새 자료를 반영할 때는 별도 복사본에서 준비한 뒤 원자료 합계·누락 행·연령 구간·기준일·공간 단위·출처 표시를 재확인하십시오.

주요 원천: [서울 상권분석 데이터 출처](https://golmok.seoul.go.kr/source.do), [서울 길단위인구](https://data.seoul.go.kr/dataList/OA-15568/A/1/datasetView.do), [신주쿠구 인구자료](https://www.city.shinjuku.lg.jp/kusei/file02_00026.html). 개별 자료·매물 링크와 기준일은 앱의 출처 화면 및 포함된 JSON에 기록되어 있습니다.

## 화면과 연결 동작 확인

390px 및 360px 모바일 폭에서 조건 입력, 추천 제외 이유, 포장 주문량 계산, 미확인 매물 비용의 계산·저장 차단, 국가별 통화 분리, 운영안 저장, 경쟁점 메모 추가·수정·삭제, 현장 체크를 브라우저로 확인했습니다. 360px에서 가로 넘침을 수정했습니다. 검토 브라우저는 WebGL2를 제공하지 않아 도로 배경 대신 좌표 위치 비교도를 확인했습니다.

일본 매물 `jp-404586`의 별도 월 지원비 1,100엔은 해당 매물 적용 시 월 비용에 추가됩니다. 관리비 0엔과 별개이며, 기타 고정비에 중복 입력하지 않도록 화면에 안내합니다. 초기 사례금·보증·열쇠 비용은 공개 조건을 확인해 개점 부대비로 입력해야 합니다.
